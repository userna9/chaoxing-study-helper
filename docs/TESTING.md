# 测试范围

项目包含从 0.6.7 迁移的 151 个离线场景，覆盖实际播放流程、后台事件、字体目录、题图绘制命令、AI 请求、密钥持久化、测验提交确认、重复提交保护和跨章节协调。公开项目中的课程标识与题库均为模拟数据。

打包前已将项目 ZIP 解压到新目录，使用锁文件重新安装开发依赖，并通过全部 151 项检查。该次结果见 [validation.json](validation.json)；后续修改仍应重新运行测试。

运行 `npm run build` 后执行 `npm test`；最终数量与结果以 `reports/test-results.json` 为准。`npm run check:package` 检查仓库结构及常见密钥、个人路径模式；它不是通用秘密检测器。

## 能证明的内容

- 对应模拟页面结构中的解析、事件和状态转换。
- 配置在新适配器实例中重新读取，空密钥保存保留原值，清除后不会从旧记录恢复。
- 模拟接口异常或答案不完整时，不执行最终提交。
- 启用图片选项后，未还原的题目可走图片请求；关闭时不发送题图。
- 模拟两章流程中，先确认平台状态再继续。

## 尚不能证明的内容

- 当前版本在任意真实课程中都能连续完成。
- Canvas/FontFace 测试使用模拟对象，不能证明题图的实际像素可读性。
- 模拟模型响应不能证明真实 AI 的答案正确率或视觉能力。
- 真实服务的限流、鉴权、页面升级、跨源框架和浏览器电源策略兼容性。

对外发布时，请区分离线检查通过与真实课程实测通过。原会话的账号、密钥、截图和学习记录未迁入项目。

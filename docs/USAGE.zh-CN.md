# 使用说明

## 连续学习

安装 `dist/chaoxing-study-helper.user.js` 后，在课程学习页刷新。默认选择实际播放，进入课程会自动发现任务；“停止全部”会同时关闭本课程自动启动，需要时重新勾选或点击开启。

流程为：识别当前任务 → 实际播放与视频内问答 → 章节测验匹配和提交 → 核对平台完成状态 → 下一任务或下一章。没有匹配完整答案、存在平台验证或不能确认提交时，会保留待处理状态。

浏览器拒绝自动播放或媒体源初始化打断播放时，脚本会按 0.35、1、2、4、8 秒间隔有限重试，并监听媒体源就绪事件。平台更换视频节点后自动重新绑定；初始化阶段重新设置静音。新媒体源就绪时可以自动接续此前等待的播放。

持续受到浏览器权限限制时，脚本会保留任务等待真实点击；它不会伪造用户交互或修改浏览器权限。后台支持不能让冻结、丢弃的标签页或休眠中的电脑继续执行 JavaScript。

如果 Edge 多次静音重试后仍返回 `NotAllowedError`，请在浏览器设置中搜索“媒体自动播放”，核对是否允许自动播放，再刷新课程页。此项可能受组织策略管理；更改由用户自行完成。参见 [Edge 自动播放策略说明](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/AutoplayAllowed)。

## 配置 AI

展开“AI 答题兜底”，填写以下内容并保存。

| 项目 | 填写方式 |
| --- | --- |
| API 地址 | 完整的 Chat Completions 地址，例如 `https://服务商域名/v1/chat/completions` |
| 模型 | 服务商提供的模型 ID 或接入点 ID |
| API Key | 只填写密钥本身，不加 `Bearer` 前缀 |
| 启用 AI 兜底 | 勾选并保存后，未命中本地题库的题目可使用 AI |
| JSON 模式 | 接口明确支持时再开启 |
| 图片题和字形兜底 | 需要视觉模型；允许发送题图到该 API，默认关闭 |

面板提供豆包接口地址预填按钮。请自行确认所选模型、接入点和服务权限；`/responses` 接口不适用于当前适配器。

“测试接口”发送一个文字样例，不会填写或提交课程题目，也不能证明模型支持图片。测试通过并不自动启用未保存的配置。

密钥保存后输入框清空是界面不回显；以密钥状态文字为准。以后保存时留空会保留旧密钥，只有显式点击“清除密钥”才会清除。更换接口域名需要填写该域名对应的密钥。

## 混淆字体与图片兜底

页面上能看清的字，复制或读取后可能是替换字符。脚本先尝试读取字体字符目录并还原。无法确认全部字形时，不将乱码直接作为文字题发送给 AI。

若已经启用 AI，仍遇到“字体字符未还原”，可以勾选“图片题和字形兜底”并保存。脚本用原字体只绘制该题题干和选项，在对应题目下提供“本题字形兜底图片”预览。配置变化后，自动测验开启时会自动重试。

## 本地题库

展开“本地题库 JSON”粘贴并保存。题干匹配可以不指定课程；按题号匹配必须同时给出 `courseId` 或 `workId`，防止跨课程误用。

```json
[
  {
    "question": "这是一个测试用判断题。",
    "answers": ["对"]
  },
  {
    "courseId": "你的课程号",
    "questionId": "你的题号",
    "answers": ["A", "C"]
  }
]
```

项目不自带真实课程答案。不要将私人题库或带课程令牌的链接提交到公开仓库。

## 诊断

| 状态 | 含义与处理 |
| --- | --- |
| 未发现已加载的题目 | 查看是否已进入章节测验及嵌套框架是否加载 |
| 已识别若干题，但字体未还原 | 查看字体日志；必要时使用已启用的视觉兜底 |
| AI 认证失败 | 检查接口域名、密钥、模型权限 |
| AI 返回 HTTP 400 | 检查接口格式及模型是否支持当前文字或图片输入 |
| 仅匹配部分题目 | 剩余题目未解决，脚本不会提交整份测验 |
| 已发起提交，等待确认 | 核对原页面结果，不要反复交卷；只有确定需要重试时才清除待确认记录 |
| 页面未更新或无法导航 | 查看目录筛选和原页面提示；脚本不会猜测一个未核实的目标章节 |

提交 Issue 前遮盖密钥、Cookie、账号和 URL 中的令牌。

# 学习通助手

适用于超星学习通课程页的 Tampermonkey 用户脚本。自动发现视频和章节测验，使用实际播放器学习；根据平台返回的完成状态切换任务与章节。可选接入本地题库、第三方题库及用户自行配置的 AI 接口。

当前版本 **0.6.8**。项目包含可安装脚本、分模块源码和离线回归测试。当前版本的字形图片兜底尚未在所有课程、浏览器及真实视觉接口中验证，具体限制见[测试说明](docs/TESTING.md)。

## 安装与使用

1. 安装 Tampermonkey，打开 [dist/chaoxing-study-helper.user.js](dist/chaoxing-study-helper.user.js)，选择 **Raw** 获取完整脚本，或将其内容粘贴到油猴编辑器。
2. 保存脚本，进入学习通课程学习页并刷新。
3. 确认出现“自动连续学习 · 0.6.8”。按需配置 AI 或本地题库。

从旧版升级时，请完整覆盖原油猴条目，保持一个副本运行。脚本特意保留原有名称与命名空间，以沿用已保存的配置；项目目录名不影响脚本存储。

详细操作见[使用说明](docs/USAGE.zh-CN.md)。准备自己上传仓库，见[GitHub 上传步骤](docs/UPLOAD.zh-CN.md)。

## 功能

- 自动发现音视频任务、视频内问答与章节测验。
- 默认使用实际播放器；任务完成后核对平台状态，再切换任务点或下一章节。
- 在允许的浏览器状态下保持后台播放；自动播放受限时静音重试，仍受限则保留任务等待点击播放。
- 识别单选、多选、判断及普通文本填空；可导入本地 JSON 题库。
- 可选调用第三方题库；限流或无结果时使用已配置的 AI。
- AI 使用 Chat Completions 兼容接口，支持持久保存密钥、答案格式检查和可配置的置信度门槛。
- 自动还原混淆字体；启用图片选项后，可将未还原题目的原始字形渲染成题图，交给支持视觉的模型。
- 提交确认与防重复交卷记录；题目未完整匹配时保留待处理状态。

自动切换以平台完成状态为准。高级面板保留了进度上报实验与诊断功能；模拟倍率不等于视频实际速度，也不保证满足服务端观看时长要求。身份验证、浏览器冻结、系统休眠及不支持的任务仍可能需要人工处理。

## AI 配置与数据流

默认不启用 AI 或第三方查题。需要时在脚本面板中填写接口地址、模型与 API Key，勾选启用并保存；后续保存时密钥留空会保留旧值。密钥使用油猴存储，界面不回显，项目不提供额外的静态加密。

| 功能 | 发送内容 | 目的地 | 默认状态 |
| --- | --- | --- | --- |
| 实际播放与提交 | 平台播放器及原页面正常产生的请求 | 学习通 | 连续学习默认启用 |
| 第三方查题 | 题干、选项、题型 | `lyck6.cn` | 关闭 |
| AI 文字答题 | 题干、选项、题型 | 用户配置的 API | 关闭 |
| 图片题与字形兜底 | 题目图片，或仅含本题题干和选项的渲染图 | 用户配置的 API | 关闭 |
| 字体特征表 | 静态字形表下载请求 | `cdn.ocsjs.com` | 还原字体时请求 |

AI 与第三方查题请求不附带学习通 Cookie、账号或课程网址。`@connect *` 用于适配用户自定义的 AI 域名，不表示会向所有域名发送请求。外部题库、字体资源和模型服务的可用性由对应服务决定。

## 开发

需要 Node.js 22 或更新版本。测试依赖只用于开发，安装用户脚本无需 Node.js。

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run check:package
```

统一检查命令为 `npm run check`。版本号在 `package.json` 中维护；构建会同步脚本头部及面板版本。请修改 `src/`，再生成 `dist/`，不要只修改安装文件。

```text
src/          功能模块与带许可证的字体辅助代码
scripts/      可重复构建、测试和打包前检查
test/         模拟页面、模拟接口及回归用例
dist/         可直接安装的单文件用户脚本
docs/         使用、开发、测试及上传说明
.github/      GitHub Actions 与问题反馈模板
```

GitHub Actions 会检查构建产物和测试，不自动发布或上传任何课程数据。参见[开发说明](docs/DEVELOPMENT.md)。
